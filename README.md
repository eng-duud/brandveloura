# Brand Veloura — متجر العطور والساعات ومستحضرات التجميل الفاخرة (PWA)

متجر إلكتروني تقدمي فائق السرعة والأناقة، مصمم خصيصاً لقطاع المنتجات الفاخرة ومخصص للسوق اليمني، مبني بالكامل على **Django 5.x + HTMX + Tailwind CSS** مع دعم **قواعد بيانات PostgreSQL** وتخزين سحابي للصور عبر **Cloudinary**.

---

## 🌟 أبرز مميزات النظام

1. **نظام التسعير الذكي المزدوج (YER / SAR):**
   - إدخال سعر المنتج بالريال اليمني في لوحة التحكم، وحسابه آلياً بالريال السعودي بناءً على سعر الصرف المحدد.
   - إمكانية تحديث سعر الصرف اليومي بنقرة زر واحدة من لوحة التحكم لينعكس فوراً على كل أسعار المتجر.
   - زر تبديل سلس للمشتري في الهيدر لعرض الأسعار بالريال اليمني أو السعودي.

2. **تدفق الدفع اليدوي والتحقق الموثق (Manual Payment Flow):**
   - دعم حسابات البنوك والمحافظ اليمنية: **الكريمي جوال، محفظة جوالي، محفظة كاش، شبكات الحوالات، والدفع عند الاستلام (COD)**.
   - زر "نسخ رقم الحساب" بنقرة واحدة لتسهيل التحويل على العميل.
   - إمكانية رفع صورة سند/إشعار التحويل المالي أو كتابة رقم الحوالة مباشرة.
   - لوحة فحص وتكبير السندات في لوحة الإدارة (Lightbox Zoom) لاعتماد الطلب وتحديث حالته بنقرة واحدة.
   - زر مباشر لمشاركة تفاصيل الفاتورة والسند عبر **واتساب (WhatsApp)** لتأكيد الطلب فوراً.

3. **مواصفات ذكية متخصصة لكل قسم:**
   - **العطور:** الهرم العطري (قمة، قلب، قاعدة)، التركيز (Parfum/EDP)، الحجم بالمل، والفئة.
   - **الساعات:** مقاس الميناء، نوع السوار، نوع المحرك، مقاومة الماء، وسنوات الضمان.
   - **التجميل والعناية:** درجات الألوان (Color Swatches)، نوع البشرة المستهدف، والحجم.

4. **تطبيق ويب تقدمي (PWA) فائق السرعة:**
   - شريط ملاحة سفلي (Bottom Navigation) يمنح تجربة تطبيق هاتف أصلي.
   - بانر ذكي لتثبيت التطبيق على الشاشة الرئيسية (Install App).
   - تخزين محلي (Offline Caching) عبر Service Worker يفتح بسرعة حتى مع ضعف الإنترنت.
   - حجم مكتبة HTMX التفاعلية 14KB فقط دون الحاجة لحزم React الثقيلة.

## 🚀 التشغيل والتجربة محلياً (Local Development)

### 1. تفعيل البيئة الافتراضية
```bash
# على ويندوز (PowerShell):
.\.venv\Scripts\Activate.ps1

# أو مباشرة عبر مسار بايثون:
.\.venv\Scripts\python manage.py runserver
```

### 2. بيانات الدخول للوحة التحكم الإدارية
- الرابط: `http://127.0.0.1:8000/admin/`
- اسم المستخدم: **`admin`**
- كلمة المرور: **`admin123456`**

> **ملاحظة:** تم تضمين أمر بذور البيانات `python manage.py seed_data` لتعبئة المتجر بمنتجات فاخرة وحسابات الكريمي والمحافظ ومناطق الشحن تلقائياً.

## ☁️ خيارات الرفع والاستضافة السهلة (Easy Deployment)

### الخيار 1: عبر خادم خاص VPS (Hetzner, Hostinger, DigitalOcean) باستخدام Docker
الملف `docker-compose.yml` جاهز ويشمل خادم الويب وقاعدة بيانات PostgreSQL:
```bash
docker compose up -d --build
```

### الخيار 2: الرفع على المنصات السحابية (Railway / Render)
1. قم برفع المشروع على حساب GitHub.
2. اربط المستودع في Railway أو Render.
3. أضف متغير البيئة `DATABASE_URL` (رابط قاعدة PostgreSQL السحابية).
4. أضف مفاتيح Cloudinary في إعدادات البيئة (اختياري).
5. سيتم البناء والتشغيل تلقائياً عبر `Dockerfile`.

## 📁 هيكلية المشروع

```text
brandveloura/
├── config/              # إعدادات جانغو والمسارات والـ WSGI
│   ├── settings.py      # إعدادات Unfold, PostgreSQL, Cloudinary, WhiteNoise
│   └── urls.py          # المسارات العامة والـ PWA
├── store/               # تطبيق المتجر ولوحة الإدارة
│   ├── models.py        # جداول المنتجات، الطلبات، السندات، والأسعار
│   ├── admin.py         # لوحة الإدارة الفاخرة Unfold مع معاينة وتكبير السندات
│   ├── views.py         # المعالجات التفاعلية بـ HTMX وتدفق الدفع
│   ├── urls.py          # مسارات المتجر والسلة وإتمام الطلب
│   └── management/      # أمر seed_data لتعبئة المنتجات الأولية
├── templates/           # قوالب HTML المبنية بـ Tailwind CSS و HTMX
│   ├── base.html        # القالب الأساسي وشريط الجوال السفلي و PWA
│   └── store/           # صفحات المتجر، تفاصيل المنتج، السلة، وإتمام الطلب
├── static/              # الملفات الثابتة وأيقونات التطبيق
├── Dockerfile           # ملف بناء حاوية الإنتاج
├── docker-compose.yml   # إعدادات الخادم وقاعدة البيانات
└── requirements.txt     # حزم بايثون المثبتة
```
